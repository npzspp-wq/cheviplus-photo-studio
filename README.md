# Cheviplus Photo Studio

Готовый проект для автоматической сборки автономной Windows-программы.

## Как собрать EXE

1. Распакуйте этот архив.
2. На странице репозитория GitHub нажмите **Add file → Upload files**.
3. Перетащите всё содержимое распакованной папки и нажмите **Commit changes**.
4. Откройте вкладку **Actions**.
5. Выберите **Build Windows EXE** и нажмите **Run workflow**.
6. После появления зелёной галочки откройте сборку.
7. Внизу скачайте **Cheviplus-Photo-Studio-Windows**.
8. Распакуйте архив и запускайте `Cheviplus Photo Studio.exe`.

На рабочем компьютере Python не нужен. Модель удаления фона входит в готовую сборку.
