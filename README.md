# Cheviplus Photo Studio

Windows-приложение для пакетной обработки фотографий автозапчастей: удаление старого фона, сохранение товара, установка фирменного фона и логотипа, предпросмотр и экспорт.

## Версия 5.12

Добавлена подготовленная схема продления лицензий без переустановки программы. Номер CPS и рабочее место сохраняются; сейчас продление передаётся подписанным `.cpslicense`, а формат заранее совместим с будущим сервером лицензий.

Продление можно выдать на выбранное число месяцев. Если текущая лицензия ещё действует, новый срок прибавляется к существующей дате окончания; если срок уже закончился — отсчёт идёт от даты применения продления.

Сборка 5.12 проверяется тем же Windows workflow, что и предыдущие стабильные версии.
